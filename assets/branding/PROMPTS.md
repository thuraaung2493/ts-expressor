# Generation prompts

Tool: built-in image generation, with transparent backgrounds for logos and solid backgrounds for social previews. PNG logos are kept in their original form; social cards are exported to JPEG for GitHub’s upload limit.

## Logo

Use case: logo-brand.
Asset type: standalone square transparent PNG project logo.
Primary request: create a second original project mark for "ts-expressor", a CLI that scaffolds TypeScript Express APIs and generates controllers, repositories, and validation schemas.
Input image 1 is STYLE REFERENCE ONLY: the blue/navy ID-conversion logo belongs to a sibling package by the same author, Thura Aung. Match its overall weight, polished geometric design, restrained rounded corners, balanced negative space and blue #28518D / navy #25313D / pale blue #A8C7F5 palette; invent a different symbol.
Subject: a bold coding emblem with two balanced angle-bracket shapes enclosing a forward arrow or lightning-shaped construction stroke, suggesting fast API scaffolding. Use a compact horizontal silhouette with enough open negative space to read at 32px. Make it unmistakably a programming tool, not another identity card.
Style: flat, vector-like, solid-color, minimal, crisp geometry. One centered mark on actual alpha transparency, generous margins approximately 15% on each side. No surrounding rounded-square tile. No visual mockup, drop shadows, decorative illustration, gradients, or watermark.
Text: none, no letters or words. Output a single icon only.

## Logo refinement

Edit target: the provided ts-expressor icon. Preserve its exact basic angle-bracket and forward-arrow emblem, proportions and palette. Remove ALL outer glow, blur, haze, gradients and lighting effects. Every shape must be uniformly flat filled with sharp opaque edges. Left bracket solid #28518D; right bracket and three short speed bars solid #25313D; central forward arrow solid #7FA8E0. Completely transparent background with NO semi-transparent blue fog around the edges. Recenter the same mark within a SQUARE canvas with generous equal margins, not landscape. This is a production logo, not a cinematic illustration. No text, no extra shapes, no shadow.
